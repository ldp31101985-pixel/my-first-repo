# QuickNotes

Быстрые заметки + напоминания + календарь + вложения (фото, скриншоты, PDF).
Flutter: Windows, iPhone, Android — один код.

## Запуск

```bash
flutter pub get
flutter run -d windows   # на Windows
flutter run              # на iPhone/Android (нужен Mac для iOS)
```

## Что уже есть
- Заметки с тегами, поиск, закрепление
- Напоминания (в т.ч. повтор каждый день/неделю) — системные уведомления
- Календарь с отметками дней, где есть напоминания
- Вложения: фото с камеры/галереи, файлы, PDF, скриншоты
- Данные локально: `Документы/QuickNotes/notes.json` + `attachments/`

## Чего ещё нет
- Синхронизация через Google Drive (следующий этап, нужен OAuth-ключ)
